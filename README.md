# 🌲 나무의사 2차 실기 & 필기 완벽 대비 학습 도우미

네이버 지식백과 《나무 병해충 도감》 539종 전수 데이터와 1,560장의 고해상도 사진 자료를 기반으로 제작된 나무의사 자격시험 전용 학습 웹 애플리케이션입니다.

## ✨ 주요 기능

1. **🎯 2차 실기 수목 병해충 사진 식별 퀴즈**
   - 나무의사 2차 실기 시험 유형 반영 (기주 수목 + 피해 사진 관찰 후 병명 식별)
   - 1,560장의 고해상도 피해 사진 및 부위별(성충, 유충, 병징, 자낭각 등) 사진 갤러리 지원
   - 정답 확인 시 학명, 병원체, 약제 방제 요령(살포 시기, 약제 종류) 상세 해설 제공

2. **🧠 에빙하우스 망각곡선 간격 반복 시스템 (Leitner 5단계)**
   - 인간의 기억 망각 주기에 따라 복습 주기 자동 배정 (Box 1: 오늘 ~ Box 5: 마스터)
   - 오답 시 즉시 Box 1로 강등되어 당일 집중 반복 유도

3. **🔮 AI 나무의사 핵심 암기비법 탑재**
   - 시험 단골 유형별 암기 공식 (예: `【소·솔 / 잣·북】` 재선충 공식, 파이토플라스마 동정 포인트, 기주교대 녹병류 격리 요령 등)

4. **📖 539종 전수 도감 검색기**
   - 침엽수 / 활엽수 / 상록활엽수 필터 및 실시간 키워드 검색
